ACNH RSTB Fixer

One size table for your whole mod set. For Animal Crossing: New Horizons 3.0.x.

Everything runs in your browser. Your mods and game files are never uploaded anywhere.

Why mods crash together

The game keeps a list of how much memory each file needs, romfs/System/Resource/ResourceSizeTable.srsizetable, and refuses any file bigger than its entry. Only one copy of that list is used. A mod that changes models (grass, buildings) or messages can therefore crash when another mod's list wins. This page builds one list that fits every file in all your mods.

1. Add your mods

Drop mod .zip or .7z files or mod folders here.
For a .rar, extract it first and drop the folder.

    2. Your game's size table (only if no mod has one)

    Most big mods include a size table, and the page starts from those. If none of yours does, add the ResourceSizeTable.srsizetable from your own game dump (romfs/System/Resource/).

    3. Build

    Install

    1. Switch (Atmosphère): unzip the download onto your SD card. It puts the table at atmosphere/contents/01006F8002326000/romfs/System/Resource/ResourceSizeTable.srsizetable, replacing the one that is there.
    2. Emulators with a mod list: add the download as its own mod and delete ResourceSizeTable.srsizetable from your other mods. This table already includes theirs.
    3. Build again whenever you add, remove or update a mod.
    How it works

    The page starts from the size tables your mods include (taking the larger size where they differ), then looks at every file in your mods:

    • Messages, layouts, fonts, sound banks, Bcsv tables, event flows and texture-only models: it computes the exact size the game needs. These rules match vanilla 3.0.3's own table, with a few bytes of margin.
    • Models with geometry, collision or physics: their memory depends on the shaders, so it removes their entry and the game sizes those files itself. Only the models your mods include are affected. The game's other entries stay as they are.
    • Other files (Param, Stage and so on) have no entries in the game's table, so nothing changes for them.

    An entry is only ever raised, never lowered.
