      How it works

      The game keeps a list of how much memory each file needs (ResourceSizeTable.srsizetable) and refuses any file bigger than its entry. Only one copy of that list is used, so a mod can crash when another mod's list wins. This page starts from the lists your mods include (taking the larger size where they differ), then looks at every file in your mods:

      • Messages, layouts, fonts, sound banks, Bcsv tables, event flows and texture-only models: it works out the size the game needs. These rules match vanilla 3.0.3's own table, with a few bytes of margin.
      • Models with geometry, collision or physics: their memory depends on the shaders, so it removes their entry and the game sizes those files itself. Only the models your mods include are affected.
      • Other files (Param, Stage and so on) have no entries in the game's table, so nothing changes for them.

      An entry is only ever raised, never lowered. The download is a small mod that holds only the table, laid out so it's the copy your game uses.
